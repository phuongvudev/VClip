# Ảnh cho trang chủ và tài liệu

| File | Nội dung | Ghi chú |
|---|---|---|
| `icon.png` ✅ | Icon app 256px (favicon, logo) | Tạo từ AppIcon (`make icon`) |
| `og.png` ✅ | Ảnh chia sẻ mạng xã hội 1200×630 | |
| `panel.png` | Panel VClip đang mở dưới con trỏ trong Notes | ⌘⇧4 → kéo chọn vùng |
| `settings.png` | Cửa sổ Cài đặt, tab Lưu trữ | ⌘⇧4 → Space → click cửa sổ (giữ ⌥ để bỏ bóng) |
| `installer-welcome.png` | Trang chào của bộ cài .pkg | Mở file .pkg → ⌘⇧4 → Space → click |
| `uninstall-dialog.png` | Hộp thoại **Gỡ cài đặt VClip…** | Mở hộp thoại → chụp → bấm **Huỷ** |

Nên để chiều ngang ảnh dưới 1600px cho nhẹ repo.
